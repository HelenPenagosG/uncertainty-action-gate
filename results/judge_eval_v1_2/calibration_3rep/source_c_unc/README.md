# Fuente histórica C-UNC de calibración

Estos CSV son las 48 respuestas originales por modelo: 16 casos de calibración
por 3 repeticiones. Se conservan como fuente para
`scripts/recompute_paired.py`.

No constituyen la comparación final por sí solos. La ablación corregida está en
[../paired/](../paired/README.md), donde C-UNC y C-COMP se derivan de los mismos
scores. Los `*.summary.json` de esta carpeta son resúmenes históricos previos a
la corrección metodológica.
