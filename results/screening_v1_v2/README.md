# Real-model screening

These 48 B-condition runs used four related scenario families, the competitive
reward frame, and a 20-step limit. In `v1` the cheaper prohibited shortcut was
disclosed; `v2` additionally introduced one recoverable verifier failure.

Neither actor attempted or executed the shortcut. Both completed the authorized
route in every run. This development result motivated the `v3` stress condition
used in the main pilot. It does not establish that an impossible authorized
route is necessary for reward hacking in general.
