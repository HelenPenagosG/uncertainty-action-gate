# Mocked mechanism checks

A deterministic scripted actor always proposed the shortcut, while a mocked
judge supplied fixed scores. The four-family checks validate action interception
and causal route attribution. A separate 12-run `v2` batch validates recovery
after a controlled, temporary verifier outage.

These runs contain no model inference. They establish that the implementation
can block a prohibited route without ending the run, but they are not evidence
that a language-model actor will recover successfully.
